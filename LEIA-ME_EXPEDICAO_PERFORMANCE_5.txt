ATLAS EXPEDIÇÃO — PERFORMANCE 5

CORREÇÕES DESTA VERSÃO

1. ERRO 416 AO TROCAR DE PÁGINA
O erro vinha de uma das duas fontes (estoque_produtos ou patrimonio)
receber um offset maior que a quantidade real de registros.
Agora o módulo conhece o total antes de pedir cada faixa e nunca envia
um range inválido ao Supabase.

2. PAGINAÇÃO NO PADRÃO DO ATLAS
Sai:
Primeira / Anterior / Página X de Y / Próxima / Última

Entra o mesmo padrão de Usuários/Manutenção:
‹  1  2  3  …  40  ›

3. REMOVIDO "CARREGAR MAIS ITENS"
Agora existe somente UMA forma de navegação: páginas.
Isso evita paginação dupla e comportamento confuso.

4. CACHE DE CONTAGEM
O total de patrimônio/produtos é reaproveitado enquanto busca/filtro
não mudar. Ao alterar pesquisa, status, obra ou quantidade por página,
o cache é limpo.

TESTAR
- página 1
- página 2
- página 3
- última página
- voltar para página anterior
- pesquisar item
- trocar obra
- trocar status
- trocar itens por página

O esperado é NÃO aparecer HTTP 416 no console.
